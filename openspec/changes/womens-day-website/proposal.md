## Why

Ngày Quốc tế Phụ nữ 8/3 đang đến gần, cần một website chúc mừng đồng nghiệp nữ với theme hồng phấn, cute, nữ tính. Website sẽ được host trên GitHub Pages để dễ chia sẻ link cho mọi người.

## What Changes

- Tạo mới hoàn toàn một React + Vite website chúc mừng ngày 8/3
- Theme màu hồng phấn (pastel pink), cute, nữ tính
- Hiệu ứng animation: confetti, particles hoa, fireworks
- Các section: Loading screen, lời chúc, gallery ảnh, timeline, nhạc nền
- Responsive design cho mobile và desktop
- Cấu hình deploy lên GitHub Pages
- Tham khảo cấu trúc từ template GFBD (React + Vite + Tailwind CSS)

## Capabilities

### New Capabilities
- `landing-page`: Trang chủ với loading screen, tiêu đề chúc mừng 8/3, hiệu ứng hoa rơi và confetti
- `wish-messages`: Section hiển thị lời chúc mừng ngày 8/3 cho đồng nghiệp nữ với animation đẹp
- `photo-gallery`: Gallery ảnh kỷ niệm với đồng nghiệp, hỗ trợ lightbox xem ảnh lớn
- `music-player`: Trình phát nhạc nền tự động hoặc bật/tắt bởi người dùng
- `visual-effects`: Hiệu ứng visual: particle hoa, confetti, fireworks, custom cursor
- `github-pages-deploy`: Cấu hình CI/CD deploy tự động lên GitHub Pages

## Impact

- **Dependencies mới**: React, Vite, Tailwind CSS, animejs, react-confetti, react-icons, react-bootstrap
- **Hosting**: GitHub Pages (github.io)
- **CI/CD**: GitHub Actions workflow cho auto deploy
- **Assets**: Cần chuẩn bị ảnh đồng nghiệp, nhạc nền, font chữ
